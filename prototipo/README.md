# Nucleo del prototipo — snapshot di riferimento

Questa è una copia del codice `pipeline_demo/` presente nel pacchetto del selettore S2. È uno **snapshot del nucleo sperimentale**, non necessariamente l’intera interfaccia utente della demo. La descrizione del selettore e dei test che hanno portato a questa configurazione è in [`../esperimenti/04-selettori.md`](../esperimenti/04-selettori.md).

La configurazione candidata è X0+C2+Z+S2-V. Per eseguire il codice occorrono il modello GGUF locale e un runtime llama.cpp configurato sul computer: non sono inclusi nell’archivio.
